# UI Icon Standard

For this project, we will use `lucide-react` as the standard icon library to ensure consistency and quality across the user interface.

## Guidelines

- **Always use `lucide-react`:** For any new icons, import them directly from the `lucide-react` library.
- **Replace existing icons:** Any existing icons (such as custom SVGs, Heroicons, etc.) should be replaced with an appropriate equivalent from `lucide-react`.
- **Consistency is key:** Ensure that icons are used consistently across all components (buttons, navigation, feature cards, etc.).
- **Installation:** The library is installed as a dependency. If it's missing, run `npm install lucide-react`.
